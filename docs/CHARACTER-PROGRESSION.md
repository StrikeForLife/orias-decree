# 屬性分配與介面驗收

DM 在「DM 管理」調整角色等級，不再直接修改六屬性。原有戰役、全隊長休、法術名額及一次性重選許可保留。DM 編輯角色 API 收到 `stats` 時回傳 403，不會部分套用請求。

角色擁有者在「我的角色 → 冒險裝備」六屬性下方分配成長點。2／4／6／8 級各取得一點，可以保留未分配點數；每項屬性總值上限 +5。儲存使用角色版本檢查，並由後端重新驗證點數及計算衍生數值。變更最大生命／意志不會自動補滿當前資源。

若降級後可用成長點少於已分配點數，DM 更新會回傳 409，玩家需先降低成長分配；系統不會代選扣除哪項屬性。舊角色沒有 `_baseStats` 時保留現有屬性並顯示說明，不自動推算建角來源。本次沒有新增修復舊角色分配紀錄的工具或 migration。

建角使用六屬性滑桿，顯示剩餘的 14 點；可降至 −3，至多一項 +4。職業、法源道與出身選擇沿用典籍配色。候選法術與已選法術分欄；核心法術固定保留並佔一名額，名額滿時阻止再加入。一次性重選法術使用同一選取介面與現有後端候選範圍。

## 本機驗收

1. DM 調高等級，玩家重新載入後確認成長點增加；其他玩家與 DM 不能替角色分配成長點。
2. 玩家調整滑桿，核對剩餘點數與總屬性；超額不能儲存，版本過期保留錯誤提示。
3. 建角選擇不同職業／法源道／出身，確認配色、候選範圍及核心法術隨之更新。一般法術可往返兩欄，核心不能移除，總數不超過名額。
4. 檢視生命／意志框、職業與法源道典籍、出身典籍及四類武器；搜尋與右側詳情保持可用，信仰典籍沿用原有樣式。
5. 使用玩家及 DM 帳號驗收私人筆記、典藏管理室與一次性重選許可。測試環境的視覺 fixture 不代表真實 Google／Cloudflare 端對端驗證。

發布仍依 `docs/RELEASING.md`，本次不需要資料庫 migration。

## 動態回饋

導覽布旗尾端垂出頁首，切換時短暫擺動；中央分頁、管理視窗與右側詳情使用短暫淡入／位移。隊伍 AC／DC 各佔資源列的一半寬度。

受傷與祈禱在資源 API 確認成功後才播放震動／光暈；失敗、重播操作及已切換的角色不播放。動畫不延遲請求、不改動數值，並遵從 `prefers-reduced-motion`。正式 Google／Cloudflare 的端對端驗收仍由發布者完成。
